Controlul agenției

Introdu tokenul privat AGENT_CITY_ACCESS_TOKEN. Autentificarea este verificată de server; tokenul rămâne doar în memoria acestei pagini, nu în stocarea browserului.

Nu trimite tokenul prin chat. Linkul paginii poate fi accesat public, însă datele de server sunt protejate prin autentificare.

Limite de utilizare

Vercel serverless nu garantează contoare comune între instanțe. Aceste valori sunt informative, nu o măsurare de billing.

Proiectele și misiunile existente sunt păstrate în localStorage din acest browser. Panoul nu poate vedea automat datele de pe alt telefon sau calculator. Pentru sincronizare reală este necesară o bază de date și autentificare multi-utilizator.

Politici owner
Tokenul este păstrat doar în RAM-ul paginii și este verificat pe server la fiecare acces admin. Deconectarea îl elimină. Folosește HTTPS și nu partaja tokenul.
Momentan același token protejează funcțiile AI și administrația. Nu este încă un sistem de roluri sau autentificare individuală; pentru echipă trebuie adăugat login separat și o bază de date.
